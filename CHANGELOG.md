# Changelog

All notable changes to **drawio-engineering-mcp** are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0]: 2026-05-13

### Changed
- **License: Apache-2.0 → AGPL-3.0-or-later.** Aligns with the
  eng-mcp-suite toolkit-wide AGPL move. The upstream draw.io MCP
  foundation remains Apache-2.0; this server's engineering extensions
  are AGPL-3.0-or-later. See the
  [LICENSE_SUMMARY](https://github.com/RFingAdam/eng-mcp-suite/blob/main/LICENSE_SUMMARY.md)
  for the toolkit-wide rationale.

## [1.0.0]

Initial public release. Draw.io MCP server for RF, electrical, PCB, and
EMC engineering diagrams: 10 tools, 269 stencil symbols.
